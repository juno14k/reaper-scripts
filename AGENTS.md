# Agent instructions

## Commits

- Always add yourself as co-author with a `Co-Authored-By:` trailer.
- The message is a single compact, precise title line. No description body.

## Scripts: naming and layout

- Every script is named `juno_PascalCase.lua` (e.g. `juno_SplitVoices.lua`), and its `@description` starts with `juno: `.
- Top-level folders are ReaPack categories (`MIDI/`, `Items/`, `Tracks/`...). The main script sits directly in its category folder and holds the ReaPack package header (`@description`, `@author`, `@version`, `@changelog`, `@provides`, `@about`).
- Helper files go in a folder named after the script, next to it (`MIDI/juno_SplitVoices/core.lua`). They are listed in the main script's `@provides` as `[nomain]` and contain `-- @noindex`.
- Multiple scripts in one package (e.g. a forward/backward pair) are listed in `@provides` as `[main]`.
- A package may use another package's helper file (ReaPack has no dependencies, so the script checks for it and tells the user to install it). Both must sit in the same category folder. `MIDI/juno_SplitVoices/core.lua` is used this way by `juno_MIDIExportHelper`: if you change how `Core.Split` is called or what it returns, bump `Core.API_VERSION` and update the scripts that use it.
- `index.xml` is generated by CI (`reapack-index`) on push to `master`. Never edit it by hand. To release, bump `@version` and write a `@changelog`.

## Tests

- `.tests/` holds tests that run the scripts against a mocked REAPER and ReaImGui (`.tests/helpers.lua`). Run them with plain Lua 5.4 from anywhere: `lua .tests/run_all.lua`.
- Every file in `.tests/` starts with `-- @noindex`, in case reapack-index treats the folder as a category.
- When you change a script, run the tests; when you fix a bug or add a feature, add a test for it.
